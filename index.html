💡 How Stable Diffusion Synthesizes High-Resolution Images from Noise

1. Text Representation (CLIP): When you input a text prompt, the CLIP ViT-L/14 text encoder parses words into discrete tokens and maps each token into a 768-dimensional semantic embedding vector. These token vectors serve as the continuous semantic compass guiding image synthesis.


2. The Latent Space ($64 \times 64 \times 4$): Rather than manipulating millions of pixel values directly (which is computationally prohibitive), Stable Diffusion operates inside a compressed 4-channel latent space trained via an autoencoder (VAE). The 4 channels capture low-frequency luminance, chromatic axes, and edge textures with a 48× reduction in total dimensions.


3. U-Net & Cross-Attention: Across 50 denoising timesteps ($t = 1000 \to 0$), the 860M parameter U-Net predicts the precise Gaussian noise vector $\epsilon_\theta$ contained in the latent. Inside each spatial transformer block, Cross-Attention correlates spatial image query vectors ($Q$) with text key/value vectors ($K, V$), ensuring features like "astronaut helmet" or "neon lights" coalesce in the designated spatial regions.


4. Classifier-Free Guidance (CFG): To strictly enforce prompt adherence without degrading image quality, the model evaluates two noise estimates per step: one with your text prompt and one without (unconditional). Multiplying the difference vector by the guidance scale $s$ (typically $7.0\text{–}8.5$) amplifies semantic details while preserving realistic visual coherence.


5. VAE Image Decoding: Once the latent representation is completely denoised at $t=0$, it is passed through the VAE Decoder only once, expanding the $64 \times 64 \times 4$ latent array into a crisp, high-resolution $512 \times 512 \times 3$ RGB image.
